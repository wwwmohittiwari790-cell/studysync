# StudySync – Smart Student Planner

A responsive college-project website built using HTML, CSS and vanilla JavaScript.

## Features
- Assignment tracker with due dates and completion progress
- Weekly class timetable
- Attendance percentage calculator and 75% target guidance
- Rotating study tips
- Browser localStorage persistence

## Run
Open `index.html` in a browser.

## Host on GitHub Pages
Create a public GitHub repository, upload `index.html` to the repository root, then go to Settings > Pages > Deploy from a branch > main > /(root) > Save.

Note: This is a frontend-only demonstration. Saved tasks and classes are specific to each browser/device, not shared between users.
